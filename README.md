# 💙 DevHub

Willkommen im Repository von **DevHub**!

DevHub ist eine deutschsprachige Community für Programmierung, Technik, eigene Projekte und entspanntes Zusammensein.

Du musst kein Programmierer sein, um dazuzugehören. Bei uns sind Anfänger, Technikinteressierte und alle willkommen, die neue Leute kennenlernen oder einfach chillen möchten.
